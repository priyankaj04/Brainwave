## Overview


Brainwave is a cutting-edge web application designed to showcase advanced frontend development skills with a futuristic aesthetic. The app leverages OpenAI's powerful APIs to provide users with a seamless experience where they can interact with AI, generate media, and manage content all through a beautifully designed dashboard. Built with Next.js, TypeScript, and Prisma, Brainwave is a testament to modern web development practices and responsive design.


## Features


* `AI-Powered Chat`: Engage in dynamic conversations with an AI, powered by OpenAI's APIs.
* `Media Generation`: Generate images, videos, documents, and audio files using AI capabilities directly from the dashboard.
* `File Sharing`: Upload and share images, videos, and documents within the platform.
* `Responsive Design`: Experience a sleek, futuristic interface optimized for all devices, thanks to Tailwind CSS.


## Technologies Used


* `Next.js`: A versatile React framework that powers the server-side rendering and static site generation of the app.
* `TypeScript`: Enhances JavaScript with static typing, making the code more reliable and maintainable.
* `Prisma`: An ORM that simplifies database management and querying, ensuring efficient data handling.
* `OpenAI APIs`: The core of the AI features, providing advanced machine learning models for natural language processing and media generation.
* `Tailwind CSS`: A utility-first CSS framework that enables the creation of a highly responsive and modern design.
* `Stripe`: A powerful payment processing platform used in the app's chatbox feature. It allows users to seamlessly handle payments for advanced queries or services, ensuring secure transactions.
* `Clerk`: A robust authentication and authorization platform that manages user login and access control. It provides a secure and user-friendly way for users to sign in, register, and manage their accounts within the app.


## How It Works


<b>Dashboard</b>
The dashboard is the central hub where users can interact with all the features of the Brainwave app:


* `Chat with AI`: Users can start a conversation with the AI by typing messages. The AI responds in real-time, offering insights, generating text, or even assisting with content creation.
* `Media Generation`: Through the dashboard, users can input prompts to generate images, videos, documents, and audio files. The AI processes these requests and provides the generated content, which users can then download or share.
* `File Upload and Sharing`: Users can upload images, videos, and documents. These files can be shared within the platform, making it easy to collaborate or showcase work.
* `Responsive Design`: The dashboard is designed to look stunning on all devices, whether on a desktop, tablet, or smartphone, ensuring a consistent user experience.


## Setting Up Environment Variables

Create a `.env` file in the root directory and add the following environment variables:

* `OPENAI_API_KEY`: Your OpenAI API key for accessing AI services.
* `DATABASE_URL`: The connection string for your Prisma-managed database.
